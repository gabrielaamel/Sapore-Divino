Sapore Divino Restaurant Website
A responsive fine‑dining restaurant website built as the final project for the IBM course Developing Websites and Front‑Ends with Bootstrap on Coursera.

The goal of this project is to design and develop a modern restaurant website using HTML, CSS, JavaScript, and Bootstrap, ensuring a seamless user experience across devices.

⭐ Overview
Sapore Divino is a fictional fine‑dining restaurant offering an elegant culinary experience.
This website includes:

A hero section with call‑to‑action

About section

Menu highlights

Photo gallery

Contact form

Reservation section

Footer with social links

The design focuses on clarity, visual appeal, and responsiveness.
